Nettside for Line-Cooperation. Hostes som statisk side på Cloudflare.

## Hosting og innhold

Siden trenger **ikke betalt hosting**. Cloudflare Pages-gratisplanen dekker drift, og kunden får enkel redigering av innhold kun.

Se beslutningen: [docs/beslutninger/001-hosting-og-innholdsredigering.md](docs/beslutninger/001-hosting-og-innholdsredigering.md).
